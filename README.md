## About me

I work where software engineering, computational modeling, and chemical processes overlap. Rather than treating theory and code separately, I take complex physical systems—like biomass reaction kinetics or climate patterns—and translate them into clean, testable software. Right now, I'm on a gap year preparing for university admissions with an interdisciplinary focus on Computer Science and Chemistry.

### What I'm focused on
- **Environmental machine learning:** Training Python models (Scikit-learn, XGBoost) to forecast environmental risks like drought by linking satellite NDVI vegetation data with space weather indices.
- **Pyrolysis reactor modeling:** Researching autothermal fast-pyrolysis kinetics, byproduct recirculation, and fuzzy PID temperature controls reaching 73.6% thermal efficiency.
- **Backend test engineering:** Building automated testing pipelines with Node.js and Mocha to keep API contracts reliable and regression-free.
- **Math and CS foundations:** Deepening my groundwork in reaction kinetics, multivariable calculus, and algorithms ahead of undergraduate studies.
